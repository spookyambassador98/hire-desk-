ПРОСТЫМИ СЛОВАМИ
----------------

Hire Desk — это твой Lead Desk, но не для поиска клиентов, а для поиска постоянной работы.

- Вместо лидов → список вакансий
- Вместо соцсетей → описание / зарплата / ссылка / шанс что возьмут / шаблон отклика
- Поиск делится на Европу и Америку
- Цель — стабильная работа (не фриланс)
- Ты: не классический проггер, а человек который делает цифровые продукты

5. КАРТОЧКА ВАКАНСИИ
--------------------

На каждой вакансии сразу видно:

  1. Компания + роль + регион (EU / US)
  2. Короткое описание
  3. Зарплата / range
  4. Ссылка (LinkedIn / careers)
  5. Fit % — насколько подходит под твои проекты
  6. Какие 1–2 проекта кидать в отклик
  7. Готовый шаблон текста
  8. Статус: new → applied → interview → offer


6. ЭКРАНЫ ПРИЛОЖЕНИЯ
--------------------

  Queue         — что отправить сегодня
  Europe        — вакансии Европы
  America       — вакансии Америки
  Applied       — уже отправил + follow-up
  Interviews    — куда позвали + brief
  Offers        — сравнение офферов
  Templates     — шаблоны писем
  Portfolio map — какой проект к какой роли
  Harvest       — импорт/парсер вакансий
  Admin         — воронка и статистика

Главный экран = сразу список вакансий, не дерево сегментов.


7. СКОРИНГ (3 числа)
--------------------

Не один красивый %, а:

  1. Fit           — совпадение с портфелем и типом роли
  2. Reachability  — легко ли откликнуться / есть ли контакт
  3. Priority      — что делать сегодня первым

9. ДНЕВНАЯ ДИСЦИПЛИНА
---------------------

  - 8–12 заявок Europe
  - 8–12 заявок America
  - Follow-up через 5–7 дней тишины
  - Лог: куда написал / что ответили

Без этого красивый список не помогает устроиться.


10. EUROPE VS AMERICA
---------------------

                    Europe                          America
  Каналы            LinkedIn, careers, EU boards    LinkedIn, Wellfound, Greenhouse
  Тон               Короче, formal                  Direct, founder-friendly
  Флаги             Remote EU / visa?               Remote US / timezone / visa?


11. ЧТО ДОБАВИЛИ СВЕРХ ТВОЕЙ ИДЕИ (ускорение найма)
----------------------------------------------------

  1. Recruiter / hiring manager — кому писать лично
  2. Follow-up шаблоны на день 3 / 7 / 14
  3. Interview brief — 3 буллета + какие демо открыть
  4. Offer tracker — сравнение офферов
  5. Rejection learning — почему отказ → подкрутка фильтров
  6. Proof pack — одна страница с лучшими кейсами
  7. Company signal — product-led вверх / body-shop вниз
  8. Anti-filter плохих ролей
  9. Portfolio matcher в карточке
 10. Daily queue + квота EU/US
